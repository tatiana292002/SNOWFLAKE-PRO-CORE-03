# Domain 2 Practice Questions

1. A user has SELECT on a table but cannot query it. What else should be checked?
   - A. Only OWNERSHIP
   - B. Database/schema USAGE and warehouse USAGE
   - C. CREATE SHARE
   - D. MANAGE ACCOUNT
   - **Answer: B**

2. Columns tagged `PII` should automatically be masked.
   - A. Row Access Policy
   - B. Tag-based masking
   - C. Resource Monitor
   - D. Network Policy
   - **Answer: B**

3. Where can a practitioner review account security posture and recommendations?
   - A. Trust Center
   - B. Query Result Cache
   - C. INFORMATION_SCHEMA
   - D. Snowpipe
   - **Answer: A**

4. A user needs privileges from multiple roles during one session.
   - A. Future grants
   - B. Secondary roles
   - C. Clone
   - D. Reader account
   - **Answer: B**

5. Which mechanism measures nulls, duplicates, row counts, and freshness?
   - A. DMF
   - B. QAS
   - C. SOS
   - D. Resource Monitor
   - **Answer: A**
