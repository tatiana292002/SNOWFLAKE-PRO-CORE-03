# Domain 3 Practice Questions

1. Remove successfully loaded files from a stage after loading.
   - A. FORCE
   - B. PURGE
   - C. VALIDATION_MODE
   - D. AUTO_INGEST
   - **Answer: B**

2. Continuous file ingestion is required.
   - A. Snowpipe
   - B. Snowpark
   - C. Materialized View
   - D. Reader account
   - **Answer: A**

3. Low-latency row ingestion without files is required.
   - A. Snowpipe Streaming
   - B. GET
   - C. External Table
   - D. Git Integration
   - **Answer: A**

4. Secure cloud-storage credentials/access should use:
   - A. API Integration
   - B. Storage Integration
   - C. Git Integration
   - D. Notification Integration
   - **Answer: B**

5. Versioned repository/deployment integration should use:
   - A. Storage Integration
   - B. API Integration
   - C. Git Integration
   - D. Snowpipe
   - **Answer: C**
