# Domain 1 Practice Questions

1. A single query spills to storage. What concept should be investigated first?
   - A. Multi-cluster
   - B. Larger warehouse
   - C. Reader account
   - D. Network policy
   - **Answer: B**

2. Hundreds of dashboards queue during peak time. What addresses concurrency?
   - A. Larger warehouse
   - B. Multi-cluster warehouse
   - C. Materialized view
   - D. Secure view
   - **Answer: B**

3. Snowpark ML repeatedly runs out of memory on Standard Medium. Which warehouse type fits the guide?
   - A. Snowpark-optimized
   - B. External
   - C. Reader
   - D. Temporary
   - **Answer: A**

4. Natural-language questions over sales tables should use:
   - A. Cortex Search
   - B. Cortex Analyst
   - C. Document AI
   - D. Directory Table
   - **Answer: B**

5. Which cache works without a running warehouse?
   - A. Warehouse cache
   - B. Query Result Cache
   - C. Local SSD cache
   - D. Stage cache
   - **Answer: B**
