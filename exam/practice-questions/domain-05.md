# Domain 5 Practice Questions

1. A consumer has no Snowflake account but must read provider data.
   - A. Reader account
   - B. Direct Secure Data Share
   - C. Dynamic Table
   - D. Stream
   - **Answer: A**

2. Two organizations need combined audience analysis without exposing raw PII.
   - A. Zero-Copy Clone
   - B. Data Clean Room
   - C. Snowpipe
   - D. Materialized View
   - **Answer: B**

3. A fast logical dev/test copy is required.
   - A. Zero-Copy Clone
   - B. Reader account
   - C. Snowpipe Streaming
   - D. Network Policy
   - **Answer: A**

4. Open format, own cloud storage, and interoperability with Spark/Trino are required.
   - A. Iceberg
   - B. Temporary table
   - C. Secure view
   - D. Query Result Cache
   - **Answer: A**

5. Regional continuity is required.
   - A. Replication + failover groups + client redirect
   - B. Resource Monitor only
   - C. Materialized View only
   - D. Snowpipe only
   - **Answer: A**
