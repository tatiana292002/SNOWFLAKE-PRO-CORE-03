# Domain 4 Practice Questions

1. A JOIN causes a huge unexpected increase in row count.
   - A. Increase warehouse size
   - B. Enable multi-cluster
   - C. Correct join logic/cardinality
   - D. Add a reader account
   - **Answer: C**

2. A huge table is searched for a small number of exact values.
   - A. Search Optimization Service
   - B. Fail-safe
   - C. Snowpipe
   - D. Resource Monitor
   - **Answer: A**

3. The same expensive aggregation is repeated while data changes relatively little.
   - A. Materialized view
   - B. Multi-cluster
   - C. Network policy
   - D. Reader account
   - **Answer: A**

4. A declarative pipeline with joins and a freshness target is required.
   - A. Dynamic Table
   - B. Secure view
   - C. Reader account
   - D. Stage
   - **Answer: A**

5. ETL and ad-hoc queries interfere on one warehouse.
   - A. Separate workloads into dedicated warehouses
   - B. Disable caching
   - C. Convert all tables to Iceberg
   - D. Disable auto-resume
   - **Answer: A**
