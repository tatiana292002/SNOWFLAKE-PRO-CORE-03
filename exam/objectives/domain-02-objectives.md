# Domain 2 Objectives — Account Management and Data Governance

**Weight: 20%**

1. Understand RBAC, privileges, and role hierarchy.
2. Understand DAC and ownership.
3. Understand managed access schemas.
4. Understand future grants.
5. Distinguish account roles and database roles.
6. Understand secondary roles.
7. Recognize account identifiers.
8. Understand authentication methods.
9. Understand network policies and precedence.
10. Distinguish masking and row access policies.
11. Understand tags and tag-based masking.
12. Understand privacy policies.
13. Recognize Trust Center.
14. Understand alerts and notifications.
15. Understand data lineage.
16. Understand Data Metric Functions.
17. Distinguish resource monitors and budgets.
18. Distinguish ACCOUNT_USAGE and INFORMATION_SCHEMA.

### Must-know
Table querying normally requires USAGE on database + schema, SELECT on table, and USAGE on warehouse. Blocked IPs override allowed IPs; user-level network policy takes priority for that user.
