# Domain 3 Objectives — Loading, Unloading, and Connectivity

**Weight: 18%**

1. Understand internal and external stages.
2. Understand PUT and GET.
3. Understand COPY INTO loading and unloading.
4. Recognize ON_ERROR options.
5. Recognize supported file formats.
6. Understand VALIDATION_MODE.
7. Understand load metadata and the guide's 64-day window.
8. Distinguish FORCE and PURGE.
9. Distinguish drivers and connectors.
10. Understand Storage Integration, API Integration, and Git Integration.
11. Understand Snowpipe.
12. Understand Snowpipe Streaming.
13. Recognize the Kafka connector.
14. Recognize Openflow and the guide's GA evaluation caveat.

### Scenario rules
- Batch → COPY INTO
- Repeated arriving files → Snowpipe
- Low-latency rows → Snowpipe Streaming
- Cloud storage credentials → Storage Integration
- External API → API Integration
- Versioned repository → Git Integration
