# Domain 5 Objectives — Data Collaboration

**Weight: 10%**

1. Understand zero-copy data sharing.
2. Distinguish Secure Data Share and reader accounts.
3. Understand Listings/Marketplace.
4. Understand Native Apps.
5. Understand cross-region/cross-cloud sharing.
6. Understand database replication and failover groups.
7. Understand client redirect.
8. Understand Data Clean Rooms.
9. Understand Zero-Copy Clone.
10. Understand stream behavior when cloning.
11. Understand Iceberg tables and catalog types.
12. Distinguish External Tables and Directory Tables.
13. Understand Time Travel and Fail-safe.

### Scenario rules
- Consumer without Snowflake → reader account
- Same region/cloud live sharing → Secure Data Share
- Cross-region/cross-cloud → replication or appropriate listing path
- Regional continuity → replication + failover groups + client redirect
- Combined analysis without raw PII exposure → Data Clean Room
- Fast dev/test copy → Zero-Copy Clone
- Open format/interoperability → Iceberg
