# Governance Exam Traps

1. Tagging classifies; tag-based masking connects a masking policy to tagged columns.
2. Data lineage is not the same as query history.
3. DMF = data quality; Resource Monitor = warehouse credit consumption.
4. ACCOUNT_USAGE = account-wide historical telemetry; INFORMATION_SCHEMA = database metadata/current state.
5. Alert = evaluates a condition and triggers an action; Notification = delivery mechanism.
6. Privacy policies are governance/privacy controls, not a replacement for RBAC.
7. Edition questions: identify every required feature and use the lowest edition described by the guide that contains them.
