# Streamlit in Snowflake

## Definition

Streamlit in Snowflake permite crear y desplegar aplicaciones de datos interactivas escritas en Python dentro de Snowflake.

## Execution Context

La guía destaca que las aplicaciones utilizan los mismos roles y permisos que el resto de la cuenta.

## Use Cases

- Crear interfaces interactivas para datos.
- Presentar resultados de análisis.
- Construir aplicaciones de datos dentro de Snowflake.

## Mental Model

```text
Streamlit = la app/interfaz que muestras al usuario
```

## Related

- Snowsight
- Snowpark
- Snowflake CLI
- Notebooks

## Exam Focus

Si el caso describe una **app de datos interactiva en Python dentro de Snowflake**, piensa en **Streamlit in Snowflake**.
