# Notifications

## Definition

Notifications son el mecanismo utilizado para entregar avisos generados por una alerta o una tarea.

## Delivery

La guía menciona entregas como:

- email;
- una cola/servicio en la nube;

mediante una **notification integration**.

## Alert vs Notification

```text
Alert        = detecta una condición
Notification = entrega el aviso
```

## Exam Focus

Si la pregunta habla de:

> avisar automáticamente cuando una condición se cumple

piensa en:

**Alert + Notification**.
