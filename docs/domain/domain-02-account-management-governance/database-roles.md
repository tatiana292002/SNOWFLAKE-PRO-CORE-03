# Database Roles

## Definition

Los **database roles** son roles definidos dentro de una base de datos.

## Purpose

Permiten asignar permisos granulares relacionados con objetos de una base de datos.

La guía destaca que son útiles para permisos que pueden viajar junto con la base cuando esta se comparte o clona.

## Account Roles vs Database Roles

| Type | Scope |
|---|---|
| Account role | Nivel de cuenta |
| Database role | Dentro de una database |

## Exam Focus

Si el caso pide permisos granulares ligados a una base de datos, considera un **database role**.
