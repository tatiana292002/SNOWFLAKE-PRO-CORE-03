# Object Tagging

## Definition

Object tagging permite asociar **tags** a objetos de Snowflake.

La guía menciona:

- databases;
- schemas;
- tables;
- columns.

## Examples

```text
COST_CENTER = 'MKT'
PII = 'true'
```

## Uses

Los tags pueden servir para:

- clasificar datos;
- activar políticas automáticas como tag-based masking;
- generar reportes de costo;
- apoyar cumplimiento.
