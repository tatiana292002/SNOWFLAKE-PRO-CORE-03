# Trust Center

## Definition

El **Trust Center** es un panel centralizado dentro de Snowsight para evaluar la postura de seguridad de una cuenta.

## Examples

La guía lo relaciona con la identificación de riesgos como:

- usuarios sin MFA;
- roles con privilegios excesivos.

También proporciona recomendaciones para corregir riesgos.

## Exam Question Pattern

> Se necesita una vista general de riesgos de seguridad y recomendaciones sin escribir consultas propias.

Respuesta:

**Trust Center**.

## Quick Rule

```text
¿Mi cuenta está bien configurada en seguridad?
→ Trust Center
```
