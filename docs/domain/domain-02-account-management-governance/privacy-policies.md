# Privacy Policies

## Definition

Las Privacy Policies están orientadas a controles de privacidad sobre datos sensibles.

La guía las relaciona con técnicas como:

- de-identificación;
- agregación mínima.

## Purpose

Se aplican sobre columnas sensibles y forman parte de las capacidades de gobierno y cumplimiento.

La guía las sitúa en el contexto de requisitos de privacidad como GDPR/HIPAA.

## Exam Focus

No confundir:

```text
Masking → ocultación de columnas según rol
Privacy policies → controles orientados a privacidad/compliance
```
