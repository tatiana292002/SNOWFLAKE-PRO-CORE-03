# Authentication

## Definition

Authentication determina cómo un usuario demuestra su identidad al iniciar sesión.

## Methods

La guía menciona:

- usuario + contraseña;
- MFA;
- key-pair authentication;
- OAuth;
- SSO/SAML;
- SCIM.

## Important Distinction

### MFA

Añade un segundo factor de autenticación.

### SSO / SAML

Permite inicio de sesión federado mediante el proveedor de identidad de la empresa.

### SCIM

Se utiliza para alta/baja y gestión automática de usuarios.

## Exam Focus

```text
Segundo factor → MFA
Inicio de sesión federado → SSO/SAML
Provisioning de usuarios → SCIM
Aplicación con OAuth → OAuth
Autenticación por llaves → Key-pair
```
