# Budgets

## Definition

Los **Budgets** ofrecen un control de costos más amplio que los Resource Monitors.

## Scope

La guía los relaciona con:

- compute;
- storage;
- serverless.

## Resource Monitor vs Budget

| Tool | Scope indicado en la guía |
|---|---|
| Resource Monitor | Créditos de warehouses |
| Budget | Compute + storage + serverless |

## Exam Focus

Si el caso pide controlar un presupuesto que incluye diferentes tipos de consumo, considera **Budgets**.

Si habla específicamente de créditos de un warehouse, considera **Resource Monitor**.
