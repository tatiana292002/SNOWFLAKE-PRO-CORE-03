# Data Lineage

## Definition

**Data lineage** muestra el origen y el recorrido de los datos.

La guía lo describe como la capacidad de saber:

- de dónde viene un dato;
- qué tabla alimentó a otra;
- con qué consulta;
- hacia dónde va.

## Uses

- Auditoría.
- Análisis de impacto de cambios.
- Comprender dependencias entre datos.

## Exam Focus

```text
¿De dónde vino este dato?
¿Qué tabla alimentó a esta otra?
→ Data lineage
```
