# Query Attribution

## ¿Qué es?

Query Attribution permite atribuir el consumo o tiempo de computación a la consulta, usuario o proceso que lo generó.

## Preguntas que ayuda a responder

- ¿Qué dashboard consume más?
- ¿Qué proceso genera más consultas?
- ¿Qué usuario o workload está provocando mayor consumo?

## Regla de examen

Si el escenario pide identificar **qué proceso o consumidor está generando el gasto**, piensa en Query Attribution y las vistas relacionadas de ACCOUNT_USAGE.
