# Stored Procedures

## ¿Qué es?

Un Stored Procedure permite encapsular lógica procedural y ejecutar operaciones SQL.

Son útiles para:

- Ejecutar SQL.
- Realizar DML.
- Encapsular procesos.
- Implementar lógica procedural.

## Diferencia rápida

```text
UDF
→ función

UDTF
→ función que devuelve filas

Stored Procedure
→ procedimiento / proceso con lógica
```

## Trampa

No confundas una función que calcula/devuelve un resultado con un procedimiento diseñado para ejecutar una secuencia de operaciones.
