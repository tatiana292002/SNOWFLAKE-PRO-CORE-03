# Snowflake Interfaces

## Snowsight

Es la interfaz web principal.

La guía la relaciona con:

- consultas;
- dashboards;
- monitoreo;
- administración;
- Notebooks.

## Snowflake CLI

Es la herramienta moderna de línea de comandos que la guía destaca para el temario actual.

Permite:

- ejecutar SQL;
- gestionar objetos;
- subir/bajar archivos;
- desplegar proyectos;
- trabajar con Snowpark y Streamlit desde terminal.

## SnowSQL

Es el cliente de línea de comandos clásico.

La guía mantiene la distinción:

- **Snowflake CLI** → CLI moderna destacada por el temario actual.
- **SnowSQL** → cliente clásico; sigue siendo relevante, por ejemplo para `PUT`/`GET`.

## IDE Integrations

Permiten trabajar contra Snowflake desde editores de código.

La guía menciona como ejemplo una extensión de Visual Studio Code.

## Snowpark

Permite programar con DataFrames en:

- Python
- Java
- Scala

La lógica se ejecuta dentro de Snowflake.

## Streamlit in Snowflake

Permite crear aplicaciones de datos interactivas en Python dentro de Snowflake.

## Drivers / Connectors

La guía menciona:

- JDBC
- ODBC
- Python
- Spark
- Kafka
- Node.js
- Go
- .NET

## Exam Focus

```text
CLI moderna → Snowflake CLI
Cliente clásico → SnowSQL
DataFrames → Snowpark
App interactiva Python → Streamlit
Editor de código → IDE integration
```
