# UDTF — User-Defined Table Functions

## ¿Qué es?

Una UDTF es una función definida por el usuario que devuelve un conjunto de filas, es decir, una tabla.

## Piensa

```text
UDF
→ función

UDTF
→ función que devuelve filas / tabla
```

La guía también destaca que una UDTF puede recibir una tabla como entrada.

## Regla

Si el escenario habla de una función cuyo resultado debe comportarse como una tabla, piensa en **UDTF**.
