# Unstructured Data

## ¿Qué es?

Son datos que no están organizados naturalmente como filas y columnas relacionales.

Ejemplos:

- PDFs.
- Imágenes.
- Documentos.
- Archivos.

## Relación con Snowflake

La guía relaciona estos datos con:

- Directory Tables.
- URLs de archivos.
- Document AI.
- Cortex.

## Comparación

```text
Structured
→ filas y columnas

Semi-structured
→ JSON / VARIANT / FLATTEN

Unstructured
→ documentos / imágenes / archivos
```
