# Domain 5: Data Collaboration (10% of exam)

## Overview

This domain covers Snowflake's data sharing and collaboration capabilities, allowing seamless sharing of data and applications across organizations without copying data.

## Topics covered

- Data Sharing
- Secure Data Sharing (SDS)
- Shares and Consumers
- Listings and Marketplace
- Data sampling and consumption limits
- Cross-region data sharing
- Time-travel for shared data
- Delta Sharing (open standard)

| `secure-data-sharing.md` | SDS and consumer management |
| `marketplace.md` | Snowflake Marketplace and listings |

| `share-permissions.md` | Rights and privilege propagation |

## Key concepts

- **Data Sharing**: Share databases/tables without copying
- **Secure Data Sharing**: Controlled access via shares
- **Shares**: Logical grouping of shared objects
- **Consumers**: Organizations receiving shared data
- **Listings**: Marketplace offerings
- **Delta Sharing**: Share with non-Snowflake systems
- **Reader Accounts**: Simplified consumer setup

## Study tips

- Understand how data sharing differs from data transfer
- Know the provider/consumer relationship
- Be familiar with Snowflake Marketplace
- Understand Delta Sharing as an open standard
- Know limitations of shared data (no direct writing)
